# SleepIn for Android

Quieter nights together. SleepIn lets you stay close in a shared room, with calls and screen sharing.

## Install or update

1. On an Android 10 or newer phone, download `SleepIn.apk` from the latest release.
2. Open the download. Android may ask you to allow installation from your browser; allow it to complete this installation.
3. Open SleepIn and join your room. The Android app supports mobile screen sharing and native call services.

Updates use the same signing key and preserve app data. Install a newer release over the existing app. Android asks for screen-sharing consent each time; some apps restrict capturing their picture or sound.

Each release includes `SHA256SUMS` and `build.json` with the version, production backend and source revision. APK signing certificate SHA-256:

## Current limits

For 1.1.0, automated web/native checks and signed packaging passed. Physical voice/shared-playback audibility, Bluetooth switching, whisper reception and a full overnight battery/reliability run remain pending. Desktop tab-capture flicker reported with some players remains a known issue. Native iOS presenting and relay support are outside this release.

This repository distributes release binaries and installation information. The application source is maintained separately.
